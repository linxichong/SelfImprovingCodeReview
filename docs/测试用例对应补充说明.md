## 解读测试证据

常规 pytest 包含对应表一致性检查，用于验证 ID 关联。上述待确认条件继续适用。
XML 各 `testcase` 的 `properties/case_ids` 对应设计 ID，`name` 的参数部分表示条件。
核对与同一设计 ID 关联的所有 `testcase`，按实际状态记录失败、跳过和未执行。
执行命令、提交 SHA、Python 和依赖版本、覆盖率按设计书另行保存。
